# Polski pakiet językowy dla filex

Tłumaczenie interfejsu [filex](https://github.com/BRF-Tech/filex) na język polski.

- **7509 / 7518** fraz przetłumaczonych
- zwalidowany oficjalnym walidatorem filex: **0 błędów, 0 ostrzeżeń**
- brakujące frazy (9) pozostają po angielsku
- część tłumaczeń jest maszynowa — poprawki są mile widziane

## Instalacja w filex (v0.43.0 lub nowszym)

W panelu administratora:

```
Plugins → Apps → Install an app → GitHub
```

Wpisz:

```
eincherjar/filex-lang-pl
```

Po instalacji wybierz język:

```
Settings → Preferences → Language → Polski
```

## Instalacja z pliku

Można też pobrać `filex-app.json` z tego repozytorium i wgrać go przez:

```
Plugins → Apps → Install an app → Files
```

Moduł pozostaw pusty — to jest pakiet językowy.

## Aktualizacja

Gdy pojawi się nowsza wersja, w `Plugins → Apps` wybierz **Upgrade** przy pozycji *Polish language pack*.

## Kompatybilność

Pakiet powstał dla katalogu fraz filex `v0.61.3`. Nowsze wersje filex mogą dodać nowe frazy — wtedy wyświetlą się po angielsku do czasu aktualizacji pakietu.
